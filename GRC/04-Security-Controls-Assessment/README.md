Security Controls Assessment

Project Overview

A simulated Governance, Risk and Compliance (GRC) assessment for a fictional UAE-based IT services company.

The project identifies information security risks, assesses security controls, documents gaps, and recommends remediation measures.

Frameworks

* ISO/IEC 27001:2022 - Information Security Management System and security controls.
* NIST Cybersecurity Framework (CSF) 2.0 - Cybersecurity risk management.
* NIST Risk Management Framework (RMF) - Information-system security risk management.

Objectives

* Identify information security risks.
* Assess selected security controls.
* Map risks and controls to relevant frameworks.
* Identify control gaps.
* Recommend remediation actions.

Scope

* Identity and access management
* Authentication
* Data protection
* Security monitoring
* Incident response
* Backup and recovery

Planned Deliverables

1. Risk register
2. Security control assessment
3. NIST CSF 2.0 gap assessment
4. NIST RMF lifecycle documentation
5. Final assessment report

Methodology

The project uses a fictional organisation and documented assumptions. Findings will distinguish simulated conditions from verified evidence.

Disclaimer

This is an educational project. It is not a formal security audit or an ISO/IEC 27001 certification assessment.
